# Karen Keyboard Academy V2

A standalone offline Karen keyboard learning and typing game.

## Main progression
1. Consonants
2. Vowels, tones and marks
3. 2-unit blends
4. 3-unit blends
5. 4-unit blends (generated from the supplied character sets)
6. Words
7. Sentences

## Game features
- ⭐ Stars
- ❤️ Hearts
- 🪙 Coins
- 🔥 Streak
- 🏆 Badges
- ❤️ Lives in games
- 📈 Levels / XP
- 📅 Daily challenge
- 🏆 Local leaderboard-style score table
- Weak-key tracking
- Keyboard memory training
- 30-second sprint
- Memory challenge
- Falling characters
- Find-the-key game

## Keyboard
The on-screen keyboard is styled as a physical keyboard with separate rows and larger Backspace, Tab, Caps Lock, Enter, Shift and Space keys.

## Customize
Edit `data/keyboard.csv` for key mappings.
Edit `data/curriculum.json` for consonants, marks and blend examples.
Edit `data/practice.txt` for additional practice text.

## Run
Unzip and open `index.html` in Chrome or Edge. No server is required.
